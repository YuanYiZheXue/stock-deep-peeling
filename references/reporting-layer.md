# 报告层 —— 三件套 + 回测 + 图表

> 穿透分析完成后，必须产出标准化交付物。

## 三件套（必做）

| 格式 | 生成方式 | 输出路径 |
|------|---------|---------|
| **MD** | 直接编写 | `wiki/报告/<标的>_深层穿透监管.md` |
| **PDF** | `scripts/charting/gen_report_pdf.py` | 同上 `.pdf` |
| **PNG** | 同上（多页长图） | 同上 `.png` |

PDF生成脚本会将MD中的图片引用替换为嵌入图片。

## 回测校准图表（有历史数据时）

三张标配图表——使用 `scripts/charting/<标的>_backtest_viz.py`：

| 图表 | 内容 |
|------|------|
| 三面板 | 股价+三次样条拟合+多项式趋势+T节点标注 / PE四色分位带 / SOTP估值区间 |
| 校准仪表盘 | 准确率条形图+偏差饼图+参数调整对比+框架评分 |
| Monte Carlo | 200条路径+中位数+50%/80%置信带 |

## 报告结构（标准模板）

```
# <标的> 九步深层穿透监管

> 分析时间 | 框架版本 | 估值方法 | 反偏见校验

## 反偏见声明
（不迷信明星企业/不迷信国企/全球对标/多方法交叉）

## 第零步：官网初诊
（官网类型诊断 + 三问题逐答）

## 第一步：金字塔定位 + 组织架构
（产业链位置 + 组织架构树 + 投资版图）

## 第二步：财务穿透 + 估值方法选择
（PE能不能用？→ SOTP/PE/DCF选择 → 三类PE → 利润质量 → 交叉验证）

## 第三步：全员穿透 + 蹲站分析
（创始人→核心团队→全员结构 + 蹲站框架 + 追问H招聘体检 + 追问C利益结构）

## 第四步：技术真伪 + 生命底色 + 业务穿透
（三相分析 + 专利/论文/软著量化 + 六条技术线 + 四大业务逐层）

## 第五步：竞争格局 + 全球对标
（四方/五方夹击 + 蹲站差 + 全球可比标的）

## 第六步：环境周期 + 政策边界
（历史节点对照 + 周期定位 + 政策红线 + 全球资源管控）

## 第七步：估值溯源 + 回测校准
（四节点回测 + 校准参数调整 + Monte Carlo模拟 + 估值交叉验证）

## 第八步：系统性风险
（逐风险标注蹲站根源 + 房地产同构检验）

## 九步汇总
（9步×发现×判断 收割表）

## 最终定性
（一句话+核心矛盾+与已扒标的蹲站对照表）
```

## 存档规则

每次分析完成后：
1. MD/PDF/PNG 存入 `wiki/报告/`
2. 在 `memory/YYYY-MM-DD.md` 追加简要记录
3. 回测数据存入 `回测/YYYY-MM-DD_标的名称/`
