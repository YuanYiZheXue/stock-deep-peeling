## ⚠️ 必读：输出规范（不读=不合格）

### 一、分析质量目录（最常犯的错误）

**目录反映的是分析深度，不是股票好坏。** 五粮液435字节的一句话摘要永远不能放A级_合格——不管多看好这只股票。

| 目录 | 含义 | 准入门槛 |
|------|------|---------|
| **A级_合格** | 分析质量A——深度充分 | ≥20KB / 九步全≥10行/步 / 全球对标表 / 政策≥3维 / 数据源声明 / WS≥12 |
| **B级_稳健** | 分析质量B——基本完整 | ≥10KB / 九步全≥5行/步 / 全球对标 / 政策≥2维 / 数据源声明 |
| **C级_部分达标** | 分析质量C——有缺失 | ≥5KB / 九步有跳过或过薄 |
| **D级_不合格** | 分析质量D——严重不足 | <5KB / 大量占位符 / 缺全球/政策/数据源 |
| **⚫级_系统性崩溃** | 分析质量⚫——不可用 | <3KB / 纯占位符 |

**每任务必自检**：谁是最弱维度？→ 那个维度决定你的目录，但是最终分析目的都是从最低级提升到最高级，也就是分析质量达到A，而不是他原本是啥就继续是啥。九步全/全球好/政策好/只有3KB → D级_不合格。

general-purpose agent不可用以下工具，必须用替代方案：

### 六、UPGRADE协议

```

```

```
1. Bash: ls 列出 task_queue 中的pending任务

5. 完成→输出→取下一个
```

## 核心分析框架

### 反偏见六铁律

**铁律一：ST禁止歧视** — ST≠自动⚫。照样走完九步。问：谁在抢救？用什么药？

**铁律二：明星禁迷信** — 看到茅台/美的/宁德不自动🟢。照样追问PE/创始人/竞争格局。

**铁律三：证据支撑** — 🟢🟡🔴⚫每个标签后有数据，不是印象。

**铁律四：极端深挖** — 巨亏追问"一次性的还是持续的"；高PE追问"分母变小还是分子变大"。

**铁律五：不跳步** — 九步必须全走完。不能因"大家都知道"跳过验证。

**铁律六：认知归零** — 每分析完一只→清除惯性→再开始下一只。连续3只相同结论→停下来问自己是不是变懒了。

## 数据源纯净度

**原则**：只从从业网站拿数据（如血压计），不从从业网站拿分析（如诊断书）。

| 级别 | 来源 | 规则 |
|------|------|------|
| 🟢 Tier 1 | 年报原文(cninfo.com.cn)/交易所/统计局/知识产权局/全球交易所/SEC EDGAR | 直接引用 |
| 🟡 Tier 2 | 东方财富F10/同花顺(仅取PE/PB/ROE数字)/企查查(股权结构) | 关键数据需年报自算验证 |
| 🔴 禁止 | 券商研报结论/雪球/百家号/自媒体/分析师一致预期/"业内人士表示" | 别人的消化产物=含系统性偏见 |

## gp-94怀疑模式：D级数据毒药识别

D级报告的每一个"~"、"约"、"估"、"N/A"都是毒药。**六大实测优先项**：

1. **市值/PE**（错误率2.5-5倍）— 实时股价×总股本=实测市值，用扣非净利润算PE
2. **扣非vs归母裂口** — 差距>30%→🔴。追问非经常收益来源
3. **"暴增X%"基数** — 同比>50%必须查前一年绝对值+前两年趋势
4. **专利数量** — 国家知识产权局实测。发明vs实用新型(发明权重×3)
5. **股息率** — 最新公告每股分红÷当前股价
6. **同行PE对比** — ≥3家国内+≥1家海外

## 全球视野（v3.1）

### 全球定价对照
每只股票必须找≥1个海外对标（找不到声明原因）。对比PE/PB/ROE/股息率/收入增速。A股溢价>2.5x全球基准→🔴。

### 全球行业竞争
- 全球统一市场(石油/有色/化工/芯片)：必须全球Top5对标
- 区域割据市场(汽车/家电/建材)：区域对标为主
- 本土封闭市场(银行/地产/传媒/中药)：国内对标为主

### 全球资源价格
主营成本中资源品>40%→必须全球价格走势+利润敏感性分析。
`利润敏感性 = (Δ资源价格% × 资源成本占比) / 净利率`

### 政策方向
每只至少检查3个政策维度：产业政策/碳中和/集采/监管。输出政策矩阵（方向/强度/对公司影响）。

## 九步分析流程

```
第0步 官网初诊       →  公司在讲什么？管理层注意力在哪？
第1步 金字塔定位     →  产业链哪个位置？护城河类型？
第2步 财务穿透       →  三类PE排列 + 利润质量 + 扣非裂口
第3步 全员穿透       →  创始人→核心层→全员金字塔
第4步 技术真伪       →  专利/论文/软著生命底色
第5步 竞争格局       →  四方夹击 + 全球行业对标
第6步 环境周期响应   →  大事件对照 + 政策分析 + 资源价格
第7步 PE溯源        →  全球PE对比 + 溢价归因
第8步 系统性风险     →  风险链 + 同构检验
```

### 第零步：官网初诊

| 官网特征 | 诊断 |
|---------|------|
| 产品文档详尽、技术论坛活跃 | 🟢 技术公司 |
| "投资者关系"比产品页面精致 | ⚫ 融资平台 |
| 新闻全是"签约/视察/合作" | 🔴 关系型公司 |
| 招聘更新频繁、技术博客持续 | 🟢 在扩张 |

### 第一步：金字塔定位

确定公司在产业链位置。越底层越安全（物理/资本壁垒），越上层越易被替代（品牌/规模壁垒）。

### 第二步：财务穿透

**PE排列诊断**：动态<滚动<静态=🟢利润加速 / 动态>滚动>静态=🔴利润萎缩 / 动态为负=⚫

**扣非裂口**：扣非与归母差距>30%→🔴粉饰信号。追问非经常收益来源。

**利润质量**：单季拆解/非经常性占比/薪酬占比/研发费用化vs资本化。

### 第三步：全员穿透

创始人→核心团队→全员结构。创始人年龄/最后原创/产业经历/历史退出。核心团队来源多样性/关键缺失。全员：博士% / 研发占比% / 人均收入。

### 第四步：技术真伪

**生命底色三件套**：
- 发明专利 = 防御纵深（软著/发明>2:1→技术含量极低）
- 学术论文 = 突破能力（无顶会论文→没做到能写论文的水平）
- 软件著作权 = 工程化能力（含金量最低）

### 第五步：竞争格局

四方夹击(上方龙头/左方替代/右方客户自研/下方开源) + 全球行业Top5对标。

### 第六步：环境周期响应

历史节点对照(2019华为制裁/2022芯片法案/AI爆发→公司做了什么) + 资源价格敏感性 + 政策矩阵(产业/碳中和/集采/监管)。

### 第七步：PE溯源

A股200倍PE无一生还。全球PE对标：A股PE vs 海外同业PE → 溢价归因(流动性/成长性/政策/品牌记忆)。

### 第八步：系统性风险

资金流转路径 + 房地产同构检验 + 风险链闭环分析。

## 精选踩坑经验

1. **PE不是越低越好**。PE从500降到300可能是靠砍薪酬硬挤的。
2. **研发费要看流向**——薪酬(流出)还是设备/技术(沉淀)。
3. **反向选择**：赛道最好公司上市了吗？没上→上市这批最需要接盘。
4. **分红是试金石**：股息率<0.5%的高PE科技股=博傻。
5. **官网泄露天机**：投资者关系比产品文档精致=融资平台不是科技公司。
6. **专利软著比是照妖镜**：软著/发明>2:1→技术含量极低。
7. **创始人用脚投票**：减持A+激励B+B在IPO前夜=真实赌注在B。
8. **关联交易是薛定谔的公允**：同一实控人=定价可"既公允又不公允"。
9. **周期顶峰信号**：价格全涨+券商全员买入+龙头加速扩产+大股东减持+关联公司抢IPO。
10. **判断力来自追问不是模板**。九步是"不漏项"，追问是"扒到骨"。
