# stock-deep-peeling — 九步扒皮法 v3

A股深度股票分析技能。逐层穿透公司基本面，区分真成长、半真半假和骗局。

## 九步流程

| 步 | 名称 | 核心问题 |
|----|------|---------|
| 0 | 官网初诊 | 管理层注意力在产品还是股价？ |
| 1 | 金字塔定位 | 产业链位置 + 护城河类型 |
| 2 | 财务穿透 | 三PE诊断 + 利润拆解 + IPO消耗 |
| 3 | 全员穿透 | 创始人→核心层→全员金字塔 + 市场认可度 |
| 4 | 技术真伪+生命底色 | 三相分析 + 专利/论文/软著深度评分 |
| 5 | 竞争格局 | 四方夹击框架 |
| 6 | 环境周期响应 | 大事件对照 + 周期定位 |
| 7 | PE溯源 | 历史200倍PE终局 + 反向选择验证 |
| 8 | 系统性风险 | 资金流转 + 房地产同构 |

v3 新增「深度追问清单」：技术底层、创始人博弈论、利益结构穿透、生态寄生检测、周期紧迫度。
